## 鲸鲨漫剧软件（本仓库，2026-11-20 起主线）
- 栈：FastAPI 引擎（127.0.0.1:7420，SQLite）+ Vue3/Vite 前端（desktop/web）+ Tauri v2 壳；PY 虚拟环境在仓库根 `.venv`
- **计费口径**：来源 owned/local 不消耗平台额度（只记 usage_events），proxy 才冻结/扣平台积分；画面 1.5 额度/张，视频 9 额度/条
- **素材必须落本机**：厂商给的是带签名会过期的预签名链接（SenseNova 24 小时），引擎生成后立刻下载到 `engine/data/assets/<项目ID>/` 并登记 assets 表，界面读本机文件
- **用户厂商现状**：只配了 SenseNova（https://token.sensenova.cn/v1）。其 Token Plan **没有视频模型**（6.8 Flash 文本 / U1·U1.5 Lite 图片），视频槽填图片模型必然 404；引擎会快速停批并提示
- 本机 ffmpeg 是 0 字节 WinGet shim（不可执行），导出 mp4 目前走"画面素材包"兜底
- 第 6 步「生成画面」用 image 能力；镜头描述取自第 5 步确认的 shots_json
