# 财务提效软件项目长期记忆
## 项目定位
财务提效工具产品矩阵：个人版(¥299买断)→代账版(¥899买断)→企业版(¥8800/年起)，共用引擎层(OCR/规则/台账/工资条)。核心买点：数据不出电脑(本地运行)、重复报销拦截、错发工资条阻断、一次买断。
## 已拍板决策(2026-11-18)
- 业余做，非全职；单人开发
- 走 T3(代账机构工作台)单独路线，不绑定银河项目
- 无种子机构资源→企业版冷启动策略=从C端代账版付费用户筛选共创
- 合规边界：只做凭证草稿，不做自动申报
- 执行顺序：C端个人版先行(1-6月)→代账版+候名单(6-12月)→企业版条件触发立项(12-18月，需C端月收入≥8000且候名单≥3家机构)
