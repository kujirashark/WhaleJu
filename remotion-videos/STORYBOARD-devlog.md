## 场景细节
### S1 Hook（0–135）full-bleed
- 背景：`step3-roles.png` 放大 1.12→1.02 缓慢推进，`blur(9px) brightness(0.72)`，叠 180° 深色渐变
- 品牌条：鳍形 logo + 「鲸鲨漫剧」+ 青色胶囊「开发进度 · Day 1」
- 主标题 86px 两行，副标 36px 等宽青色「一句话进去，一部剧出来」
- 四个步骤标签（写剧本/定角色/拆镜头/出画面）逐个淡入
- 底注：终端两行 `> 本地引擎已连接` `> 全部模型调用都留日志`
### S2 一句话起步（135–300）
- 顶部小字 `在首页输入一句话`（等宽 + 字距 0.14em）
- 输入框：圆角 20、青色描边、38px 打字机文字 + 平滑呼吸光标
- 状态行：绿点 + 「不用注册，不联网也能先跑起来」
- 终端块：本地引擎已连接 / 模型名 / 正在生成剧本
- 进度条：第 1 集 / 共 3 集，青→绿渐变填充
### S3 写剧本（300–510）
- 标题 52px + 副标「八个人生阶段，8 个亮点」
- `WindowCard`：把横屏截图包成带标题栏的窗口（圆角 18 + 阴影）
- 三张 EP 卡错峰入场（EP.01 一岁 / EP.02 五十岁 / EP.03 一百岁 + 副标题）
- 底部标签行：#童年 #亲情 #追梦 #催泪 #成长 #年代（取自真实剧本标签）
### S4 确认剧本（510–630）
- 标题两行「确认剧本 / 你点头，才往下走」
- `step2-confirm.png` 窗口卡片
- 青色勾选方块 + 「每一步都有人把关」+ 绿色「已确认」徽章
- 说明两行：剧本随时可重写，额度按成功镜头算
### S5 定角色（630–900）
- 标题 + 副标「定妆一次，全剧不换脸」
- 5 张真实定妆图 2:3 卡片横排（objectFit cover 保住人脸）
- 五条年龄锁定条：8 岁 / 22 岁 / 35 岁 / 60 岁 / 100 岁，条长递增，右侧「已锁定」
### S6 拆镜头（900–1110）
- 标题 + 副标「重要镜头和过场镜头分开算」
- 12 行真实分镜纵向滚动，两端用 mask 渐隐
- 每行：序号（等宽）+ 场景描述 + 重要/过场 标签（青色 / 灰色）
### S7 生成画面（1110–1410）
- 标题 + 副标「用的是我自己的模型账号」+ 实时计数 `n / 12`
- 4×3 网格，9:16 竖图完整显示不裁脸；每格序号角标
- 点亮节奏：每 12 帧亮起一张，刚亮的那格加青色描边
- 底部：12 个镜头 · 每镜 1.5 额度 · 失败不计费
### S8 不是黑盒（1410–1650）
- 标题「不是黑盒」+ 副标「每次调用都有日志，出了问题看得到」
- 三张要点卡（编号 1/2/3）：调用全程可见 / 密钥只留本机 / 失败不计费
- 真实调用日志样式块：200 / 429 自动重试 / 200 已落地本机
### S9 收尾（1650–1800）
- 底部 560px 一排真实画面（6 张），透明度 0.6，上方渐变过渡
- 鳍形 logo（带青色光晕脉冲）+ 「鲸鲨漫剧」+ 「还在开发中」+ 「每天更新一次进度」
- 互动引导胶囊：评论区聊聊 · 你最想让 AI 写什么故事？
- 声明：本视频画面由 AI 生成 · 素材与调用均在本机完成

## 改动指引
| 想改什么 | 改哪里 |
|---|---|
| 文案 | `src/compositions/devlog-vertical/constants.ts` 的 `CONTENT` |
| 镜头文本 | `constants.ts` 的 `SHOTS` |
| 配色 / 字号 | `constants.ts` 的 `BRAND` / `TYPO` |
| 场景时长 | `constants.ts` 的 `TIMING.scenes`（改完自动重算起始帧） |
| 画面素材 | 换 `public/assets/frames/` 与 `public/assets/roles/` 里的图 |
重新渲染：
```bash
cd remotion-videos
npx remotion render src/index.ts whale-devlog-vertical output/whale-devlog-vertical.mp4
```
