# 鲸鲨漫剧 · 60 秒产品解说视频 分镜脚本
**类型**：Product Demo（产品演示 + 解说）
**时长**：60 秒 / 1800 帧 @ 30fps
**画幅**：1920×1080（16:9 横屏）
**受众**：注册过即梦/可灵但对"做不出完整短剧"束手无策的创作者
**核心信息**：一句话想法 → 8 步流程自动带你走到成片；密钥素材不出本机；自带模型或平台额度都支持

## 场景细节
### S1 Hook（0–150）full-bleed
- 背景深空蓝；5 张剧照（child/teen/adult/mid/old）以 3D 层叠卡片从右侧错峰滑入（stagger 12 帧，spring）
- 主标题 72px 居中渐显（frame 60–90）
- 末 20 帧整体轻微缩小（scale 1.0→0.96）为场景 2 过渡
### S2 痛点（150–330）三卡纵向
- 三张痛点卡依次从左侧滑入（每张间隔 30 帧）：
  - 「角色每集换脸 ❌」
  - 「算力烧了，钱花在哪不知道 ❌」
  - 「一套流程要在 5 个工具间反复搬运 ❌」
- 每张卡出现时左侧红色竖条 growing（interpolate width 0→6px）
### S3 产品亮相（330–510）居中
- 自绘 SVG 鳍形 logo（复用产品 logo 路径）用 stroke-dashoffset 动画"画"出来（frame 0–45）
- 产品名「鲸鲨漫剧」64px spring 弹入（frame 45–75）
- 副标题「本地优先 · AI 漫剧制片台」28px 淡入（frame 75–100）
- 背景四角青色 L 形装饰角标淡入
### S4 8 步流程（510–810）时间轴
- 横向时间轴线从中间向两边展开（frame 0–40）
- 8 个步骤节点沿轴从左到右依次点亮（每步 18 帧间隔，青色圆点 + 文字）：
  写剧本 → 确认剧本 → 定角色 → 锁形象 → 拆镜头 → 生成画面 → 看成片 → 导出
- 当前点亮节点带脉冲光环
### S5 角色一致性（810–1020）五图横排
- 五张年龄剧照（child→old）依次从下方滑入（stagger 15 帧）
- 每张图右上角青色「已锁定」徽章在滑入后 10 帧弹出
- 底部金色文字「一次锁定 · 全剧一致」（frame 90–120 淡入）
### S6 双模式供给（1020–1230）三列卡片
- 三张卡片横向排列，依次 spring 弹入：
  - 「平台额度 / 零配置起步」
  - 「自带密钥 / 更省钱」
  - 「本地模型 / 完全离线」
- 三张卡底部各伸出一条青色线，汇聚到中央「生成」按钮（SVG path 描边动画）
- 按钮脉冲发光
### S7 隐私（1230–1410）中心构图
- 中央电脑图标（SVG），三条数据流箭头从电脑向外但被"LOCAL"屏障弹回
- 大字「LOCAL」等宽 96px 淡入
- 文案「密钥和素材，只留在你的电脑里」32px
### S8 价值总结（1410–1620）三大数字
- 三个数字卡依次放大：
  - 「3 集」→ 副标「从想法到成片」
  - 「8 步」→ 副标「全程对话陪跑」
  - 「0」→ 副标「数据上云」
- 数字用 countUp 动画，卡片 spring 弹入
### S9 CTA（1620–1800）居中收尾
- logo + 产品名回到中心
- 主标语「把一生，拍成一部剧」72px
- 按钮「开始创作」青底脉冲（持续）
- 底部小字「本地运行 · 数据不出电脑」
