# 双模式模型供给：代采 + BYOM 设计方案（v0.5）
> 上游：v0.4（BYOM 版方案，流程引擎/适配层/桌面架构均不变，本文只做增量）
> **本版决策（用户拍板）**：同时支持①平台代采 API（零配置一键可用）②用户自带 API（省钱+隐私）。
> 本文回答：双模式怎么共存？怎么计费？用户怎么从代采迁移到自带？代采的合规与成本怎么管？
---
## 一、为什么双模式是对的：完成获客漏斗
v0.4 只有 BYOM 时有一个未解决的矛盾：**层 1/层 2 小白连厂商账号都没注册**，"先去注册即梦、充值、粘 Key"这一步就能劝退一大半。代采模式补上这一环：
```
层1 完全小白 ──→ 代采模式起步：注册即送体验额度，零配置跑通首集
                    │ 用量上来，账单变贵
                    ▼
层2 成熟创作者 ─→ BYOM 模式：自带 Key 省 10-15%，量越大省越多
                    │ 留在平台的理由 = 流程引擎价值（不是算力绑定）
                    ▼
                 付费订阅专业版（无论哪种模式都要付软件费）
```
**核心原则：算力可以是代采的，但用户资产（项目/角色库/模板/成片率数据）永远在用户本地——迁移算力来源不迁移数据，用户没有锁定焦虑，平台不靠锁定赚钱。**
## 二、模型配置层升级：三种来源 × 四类能力槽
### 2.1 配置矩阵（FR 增量）
每个能力槽（文本/生图/生视频/TTS）独立选择来源：
| 来源 | 配置动作 | 计费 | 适用 |
|------|----------|------|------|
| A. 平台代采 | 零配置，默认可用 | 积分按量（含 10-15% 服务费） | 小白、应急补量 |
| B. 自带 Key | 选厂商→粘 Key→10 秒测试 | 软件订阅内免费，模型费付给厂商 | 成熟用户、隐私敏感 |
| C. 本地模型 | 填 Ollama/ComfyUI 地址 | 完全免费 | 零成本文本/生图 |
| 编号 | 功能 | 关键规则 | 验收标准（GWT） |
|------|------|----------|-----------------|
| FR-A1 | 来源切换器 | 每能力槽独立切来源；切换不影响已生成资产；正在跑的任务不中断 | Given 视频槽从代采切到自带可灵，When 切换，Then 进行中任务继续，下一批任务走新来源 |
| FR-A2 | 成本对比器 | 同一任务量下"代采 vs 自带"费用对比实时展示 | Given 本月代采已用 ¥120，When 查看对比，Then 显示"自带 Key 估算可省 ¥15，注册引导→" |
| FR-A3 | 体验额度 | 新用户送代采积分（够跑 1 集样片），用尽前 3 次提醒并给 BYOM 引导 | 额度耗尽时**不得静默失败**，给出三条路：充值/带 Key/本地模型 |
| FR-A4 | 混合计费 | 同一项目内允许混用（文本槽本地 Ollama + 视频槽代采 + 生图槽自带即梦） | 账单按来源分列，一目了然 |
### 2.2 路由建议联动 v0.2 方案
代采模式下路由器有天然优势（平台可看到全量成片率统计）：
- FR-A5：**成片率驱动的动态路由**——平台汇总匿名统计（哪个模型哪类镜头通过率高），代采用户的路由建议持续变准；BYOM 用户的路由建议基于其自有数据 + 平台脱敏基准
- 这让"平台代采"不只是算力转售，而是**带行业基准数据的服务**——这是纯 BYOM 竞品没有的
## 三、架构增量：桌面为主 + 轻量中转
```
桌面应用（不变，主形态）
  ├─ BYOM 请求：本机 → 直达厂商 API（零平台接触）
  └─ 代采请求：本机 → 平台中转网关（唯一需要云端的路径）
                      ├─ 统一计费/限流/积分
                      ├─ 你的 MiniMax 通道（海螺，成本优势）
                      └─ 其他厂商企业通道（按需接入）
```
| 项 | 设计 |
|----|------|
| 中转网关 | 轻量 FastAPI 网关部署在你的云主机，只做鉴权+计费+转发，无存储（不留存用户素材） |
| 故障降级 | 代采通道故障时提示用户切 BYOM 或排队，不影响 BYOM 用户 |
| 容量 | 初期并发极低（内测几十人），单机云主机足够；扩容点设在日生成量 >5000 次时 |
## 四、计费与定价（合并版）
| 项 | 定价 | 说明 |
|----|------|------|
| 软件订阅 | 免费版 / 专业版 ¥69/月·¥499/年 | 不变（v0.4） |
| 代采积分 | 按量，服务费率 10-15%（各厂商不同，页内透明展示） | 买积分包：¥30/¥100/¥500 档 |
| 体验额度 | 新用户 ¥10 等值积分（约够 1 集经济档样片） | 获客成本，计入预算 |
| BYOM | 0（模型费付厂商） | 明示"自带 Key 更省钱"，不藏 |
> 定价心理：代采赚的是"便利费"，BYOM 卖的是"软件价值"——两条腿都不靠信息差，避免"平台偷偷加价"的信任风险（费率透明公示）。
## 五、合规与风险（新增代采专属风险）
| 编号 | 风险 | 等级 | 应对 |
|------|------|------|------|
| RK-B1 | **API 转售条款**：各厂商对"代理调用/转售"政策不一，违规代采有封号风险 | **高** | 上线前逐家确认代理/分销政策（优先：MiniMax 有官方分销体系可申请；其他厂商不确定的先只支持 BYOM）；代采池只放有书面许可的通道 |
| RK-B2 | 代采通道成本波动（厂商涨价/限流） | 中 | 积分定价预留缓冲；多通道冗余 |
| RK-B3 | 中转网关成为单点故障 | 中 | 网关挂了 BYOM 照常可用（架构上已隔离）；监控告警 |
| RK-B4 | 用户对代采价格敏感（对比官方价后发现加价） | 中 | 费率透明 + 始终提供 BYOM 出口；代采价值叙事=零配置+路由数据，不是便宜 |
| RK-B5 | 体验额度被薅（批量注册） | 低 | 手机号/设备指纹限领，初期人工审核 |
## 六、MVP 范围（在 v0.4 基础上增量）
| 模块 | V1 | 说明 |
|------|-----|------|
| 适配器 | 海螺（代采通道，用你的 MiniMax 资源）+ 可灵（BYOM） | 先跑通"一代采一自带"双模式闭环 |
| 配置层 | 来源切换器（FR-A1）+ 体验额度（FR-A3）+ 成本对比（FR-A2） | FR-A5 动态路由放 V2 |
| 网关 | 最简鉴权+积分扣减+转发（单机） | — |
| 计费 | 积分包 ¥30/¥100/¥500 + 新人 ¥10 额度 | — |
**V1 验收补充**：同一用户在一次 3 集项目中，视频槽先用代采积分跑了 10 个镜头，中途切自带可灵 Key 跑完剩余 20 个镜头，资产/账单/成片率统计无缝衔接。
