> 上游：系统架构设计 4+1 视图 v2.0（已冻结）、技术概要设计 v1.0、原型 v2.0（四视图 70 交互）。

## 1. 引擎 REST API（前端 ↔ 引擎）
### 1.1 通用约定
| 项 | 约定 |
|---|---|
| Base | `http://127.0.0.1:7420/api` |
| 鉴权 | 启动时引擎生成随机 token 写 Tauri 安全存储，前端每次携带 `Authorization: Bearer <local_token>`（防本机其他进程调用） |
| 时间 | ISO 8601 带时区 `2026-11-18T21:00:00+08:00` |
| 分页 | `?limit=50&cursor=<id>`，响应 `{items, next_cursor}` |
| 错误信封 | `{"error": {"code": "E3001", "message": "中文可读", "detail": {...}}}`（错误码见 §10） |

## 2. 数据库详细设计（SQLite DDL）
> 引擎 = 唯一写者；WAL 模式；所有表带 `created_at/updated_at`（触发器维护，下略）。
```sql
-- PRAGMA journal_mode=WAL; foreign_keys=ON;
CREATE TABLE projects (
  id            TEXT PRIMARY KEY,          -- ULID
  name          TEXT NOT NULL,
  template_id   TEXT NOT NULL,             -- 'life_3ep'（V1 唯一）
  idea_text     TEXT NOT NULL,             -- 用户原始一句话
  status        TEXT NOT NULL,             -- §4 状态枚举
  deleted_at    TEXT,                      -- 软删（回收站）
  UNIQUE (id)
);
CREATE TABLE episodes (
  id          TEXT PRIMARY KEY,
  project_id  TEXT NOT NULL REFERENCES projects(id),
  idx         INTEGER NOT NULL,            -- 1..3
  status      TEXT NOT NULL DEFAULT 'pending',  -- pending|scripted|generated|exported
  UNIQUE (project_id, idx)
);
CREATE TABLE characters (
  id              TEXT PRIMARY KEY,
  project_id      TEXT NOT NULL REFERENCES projects(id),
  name            TEXT NOT NULL,
  desc_text       TEXT NOT NULL,           -- 外貌文字描述（一致性锚点）
  ref_images      TEXT NOT NULL,           -- JSON: [{asset_id, score, rank}]
  locked          INTEGER NOT NULL DEFAULT 0,
  lock_prompt_ver INTEGER,                 -- 锁定时的提示词版本
  CHECK (locked IN (0,1))
);
CREATE TABLE shots (
  id           TEXT PRIMARY KEY,
  episode_id   TEXT NOT NULL REFERENCES episodes(id),
  idx          INTEGER NOT NULL,
  scene_desc   TEXT NOT NULL,
  prompt       TEXT NOT NULL,
  prompt_ver   INTEGER NOT NULL DEFAULT 1,
  importance   TEXT NOT NULL,              -- key|transition
  ability      TEXT NOT NULL,              -- text|image|video|speech
  source       TEXT NOT NULL,              -- proxy|owned|local
  provider_id  TEXT,                       -- 运行时由路由写入
  status       TEXT NOT NULL DEFAULT 'planned'
);
CREATE TABLE generation_tasks (
  id             TEXT PRIMARY KEY,
  shot_id        TEXT NOT NULL REFERENCES shots(id),
  provider_id    TEXT NOT NULL,
  request_hash   TEXT NOT NULL,            -- 幂等键：同 shot+prompt_ver+provider 只跑一次
  status         TEXT NOT NULL,            -- queued|running|done|failed|discarded
  retry_count    INTEGER NOT NULL DEFAULT 0,
  fail_reason    TEXT,                     -- timeout|rate_limit|content_blocked|provider_error|unknown
  discard_reason TEXT,                     -- cp3_rejected|user_discard
  provider_task_id TEXT,                   -- 厂商异步任务号
  UNIQUE (shot_id, request_hash)
);
CREATE INDEX idx_tasks_status ON generation_tasks(status);
CREATE TABLE assets (
  id           TEXT PRIMARY KEY,
  project_id   TEXT NOT NULL REFERENCES projects(id),
  kind         TEXT NOT NULL,              -- image|video|audio|script|work
  local_path   TEXT NOT NULL,              -- 相对用户数据目录
  sha256       TEXT NOT NULL,
  shot_id      TEXT REFERENCES shots(id),
  character_id TEXT REFERENCES characters(id),
  size_bytes   INTEGER NOT NULL
);
CREATE TABLE checkpoints (
  id            TEXT PRIMARY KEY,
  project_id    TEXT NOT NULL REFERENCES projects(id),
  type          TEXT NOT NULL,             -- cp1|cp2|cp3
  status        TEXT NOT NULL,             -- pending|approved|rejected
  resume_payload TEXT NOT NULL,            -- JSON 快照：角色图/已耗积分/版本
  decided_at    TEXT
);
CREATE TABLE usage_events (               -- 双源记账：成片率统计的原子数据
  id            TEXT PRIMARY KEY,
  ts            TEXT NOT NULL,
  project_id    TEXT,
  provider_id   TEXT NOT NULL,
  source        TEXT NOT NULL,             -- proxy|owned|local
  ability       TEXT NOT NULL,
  units         REAL NOT NULL,
  credits_spent REAL NOT NULL DEFAULT 0,   -- BYOM=0
  raw_cost_estimate REAL NOT NULL DEFAULT 0, -- 官方口径估算
  ok            INTEGER NOT NULL,
  fail_reason   TEXT
);
CREATE INDEX idx_usage_ts ON usage_events(ts);
CREATE TABLE model_configs (
  id                 TEXT PRIMARY KEY,
  slot               TEXT NOT NULL,        -- text|image|video|speech
  source             TEXT NOT NULL,       -- proxy|owned|local
  provider_kind      TEXT NOT NULL,       -- openai_compat|kling|jimeng|helo|ollama|comfyui
  name               TEXT NOT NULL,
  endpoint           TEXT,
  credential_cipher  BLOB,                -- Vault 加密体，SQLite 永无明文 Key
  abilities          TEXT NOT NULL,       -- JSON
  is_active          INTEGER NOT NULL DEFAULT 1,
  UNIQUE (slot, is_active)                -- 同槽单激活（部分索引 WHERE is_active=1）
);
CREATE TABLE credit_wallet (
  id            INTEGER PRIMARY KEY CHECK (id = 1),   -- 单行表
  balance       REAL NOT NULL DEFAULT 0,   -- 本地缓存，网关为准
  frozen        REAL NOT NULL DEFAULT 0,
  synced_at     TEXT
);
CREATE TABLE agent_history (              -- 对话记忆（§5.3）
  id            TEXT PRIMARY KEY,
  project_id    TEXT,
  role          TEXT NOT NULL,             -- user|agent|system
  content       TEXT NOT NULL,
  intent_json   TEXT,                      -- 结构化意图（重写产物）
  summary_to    TEXT                       -- 该行之前的历史已压缩进 summary
);
```
**凭证规则**：`credential_cipher` 由引擎启动时从 OS 凭证库（Windows DPAPI / macOS Keychain，key=`mangju.engine.master`）取主密钥做 AES-256-GCM 加密。SQLite 文件被拷走时无法解密，且无明文。

## 3. Provider 适配层详细设计
### 3.1 协议数据结构（Python）
```python
@dataclass
class TextGenRequest:  prompt: str; system: str; max_tokens: int; temperature: float
@dataclass
class ImageGenRequest: prompt: str; ref_image_asset: str | None; size: str   # "1024x1536"
@dataclass
class VideoGenRequest: prompt: str; first_frame_asset: str | None
                       duration_s: int; ratio: str                          # "9:16"
@dataclass
class SpeechRequest:   text: str; voice_id: str; speed: float
@dataclass
class GenResult:
    ok: bool
    asset_ref: str | None          # 已落地的本地素材 id
    units_used: float
    raw_cost_estimate: float
    fail_reason: str | None        # §2 枚举
    provider_task_id: str | None
class Provider(Protocol):
    meta: ProviderMeta             # id, kind, source, abilities, unit_price_hint
    async def probe(self) -> ProbeResult: ...          # 10s 超时
    async def submit(self, req) -> str: ...            # 统一 submit/poll（同步能力内部即完成）
    async def poll(self, task_id) -> GenResult: ...
```
> 文本/生图为“伪异步”：`submit` 内直接完成并返回 task_id，`poll` 立即返回——**上层编排只面对一种两段式协议**。
### 3.2 路由决策（可解释规则引擎）
```python
def route(shot: Shot, cfg: ActiveConfigs, stats: SuccessStats) -> RouteDecision:
    # 优先级：用户显式指定 > 成片率统计 > 成本规则 > 默认
    # 每个决策必须产出 reason 字段，UI 强制展示（"关键镜头走可灵：成片率 78%>64%"）
```
| 槽 | 默认规则 | 换源重试 |
|---|---|---|
| text | owned(OpenAI兼容) → local(Ollama) → 提示配置（**不代采**） | 不重试（成本低，回错误） |
| image | owned(即梦) → proxy(海螺池) | ≤1 次 |
| video | key→可灵(owned优先)；transition→海螺(proxy)；统计通过率差异>15% 时反转 | ≤3 次，timeout/rate_limit 才换源 |
| speech | local(edge-tts 免费) → proxy(MiniMax) | ≤1 次 |
重试策略：`retry_count<3` 且 `fail_reason ∈ {timeout, rate_limit, provider_error}` → 换下一候选源重入队；`content_blocked` → 不重试，标记后提示用户改词（合规联动）。
### 3.3 并发与限流
```python

    "video": 3, "image": 6, "speech": 4, "text": 2}.items()}
# 厂商级追加：同一 provider_kind 并发 ≤2（防单厂商限频连坐）
```

## 4. 状态机详细迁移表
| 当前态 | 事件 | 守卫 | 动作 | 次态 |
|---|---|---|---|---|
| DRAFT | script_ready | — | 生成大纲+看点标签 | CP1_PENDING |
| CP1_PENDING | approve | — | 版本定稿 episodes.scripted | CHARACT |
| CP1_PENDING | approve | `trust_mode` | 跳过提示仍记录 checkpoints 行 | CHARACT |
| CP1_PENDING | reject | — | 保留原稿版本，prompt_ver++ | DRAFT |
| CHARACT | roles_ready | 每角色≥1 候选 | 生成打分排序 | CP2_PENDING |
| CP2_PENDING | approve | sel.size ≥ 1 | characters.locked=1，写 lock_prompt_ver | PLANNED |
| CP2_PENDING | reject | — | 重 roll（**不扣费**） | CHARACT |
| PLANNED | budget_confirmed | est_total ≤ wallet 可用 | 路由分配快照入 shots | RUNNING |
| PLANNED | budget_confirmed | 额度不足 | 返回 E2001，触发充值引导 | PLANNED |
| RUNNING | all_done | — | 合成 30s 样片 | CP3_PENDING |
| RUNNING | task_failed | retry 耗尽 | 标记 failed，继续其余镜头 | RUNNING |
| CP3_PENDING | approve | — | 全量合成入队 | DELIVER |
| CP3_PENDING | reject | — | 选中镜头 discard_reason=cp3_rejected | PLANNED |
| DELIVER | export_done | — | 写 works、发布文案缓存 | (终态) |
**恢复规则**（引擎启动扫描）：
- `CP*_PENDING` → 重读 resume_payload，推送 UI 弹窗（不自动推进）
- `RUNNING` → 未完成任务重新入队 poll（provider_task_id 仍在则续轮询，丢失则重 submit）
- `DELIVER 中断` → 导出任务重跑（幂等：sha256 相同直接复用产物）

## 5. 对话 Agent 详细设计
### 5.1 Function Calling 工具清单（白名单，全量枚举）
| 工具 | 参数 | 对应引擎动作 |
|---|---|---|
| `get_script` / `get_shots` / `get_characters` | ver? | 只读查询 |
| `regen_script` | note: str | POST /regen |
| `adjust_pacing` | episode_idx, op: speed_up\|expand, insert_count? | 改剧本后回 cost_impact |
| `swap_role_image` | role_id | 单角色重 roll |
| `answer_question` | text | 纯回复，不动状态 |
| `route_to_recharge` / `route_to_settings` | — | 前端页面跳转 |
**工具即边界**：Agent 无 `approve_checkpoint`、无 `start_generation`、无任何扣费工具——检查点确认和预算确认只能由用户在 UI 点击触发（Never 层代码化）。
### 5.2 意图改写管线（⑦ 号技术落地）
```
message → classify{剧本类|镜头类|角色类|账户类|闲聊}
        → rewrite（op+scope+cost_impact 三元组，LLM 单次调用）
        → 回显确认（SSE intent 事件）→ 用户"对" → 执行 function
        → 拒绝执行未确认过的任何写操作
```
### 5.3 记忆管理（④ 号技术落地）
- 短期：`agent_history` 最近 20 轮原文；
- 压缩：超过 20 轮时，旧对话由 LLM 压缩为 ≤200 字摘要写入 `summary_to` 指向行，之后只带摘要+近 20 轮；
- 事实记忆不进对话：角色/镜头/版本/花费全部在结构化表中，Agent 每次按需查询（`get_*` 工具），杜绝"聊着聊着忘了主角长相"。

## 6. 网关详细设计
### 6.1 API 契约（字段级）
```
POST /v1/auth/token
Body:  { "device_code": "<Tauri 首启生成，绑定安装>" }
Resp:  { "token": "jwt…", "uid": "u_01H…", "expires_in": 86400 }
GET  /v1/wallet
Resp:  { "balance": 86.4, "frozen": 12.0, "ledger_version": 128 }
POST /v1/generate/{ability}                # ability ∈ text|image|video|speech
Headers: Authorization: Bearer jwt
Body:  { "request_id": "req_01H…",        # 幂等键（引擎 ULID）
         "prompt": "…", "params": {…} }    # 无素材、无完整用户文本
Resp:  202 { "task_id": "gt_01H…" }
       402 { "error": {"code": "G4001", "message": "额度不足"} }
GET  /v1/tasks/{task_id}
Resp:  { "state": "queued|running|done|failed",
         "result_url": "https://presigned…",   # done 时，15 分钟有效
         "units_used": 9.0, "credits_charged": 10.08 }
```
### 6.2 Redis 键设计与原子计费
```
credits:{uid}:balance      # DEC（float×100 存整型分）
credits:{uid}:frozen
credits:{uid}:ledger       # STREAM：每笔变动 {ts, delta, order_id, reason}
rl:{uid}:bucket            # 令牌桶，10 req/s burst 20
task:{task_id}             # 状态缓存 TTL 24h
```
冻结→结算 Lua（原子，防并发超卖）：
```lua
-- KEYS[1]=balance KEYS[2]=frozen
-- ARGV[1]=freeze_amt ARGV[2]=actual_amt
if redis.call('GET', KEYS[1]) + 0 < tonumber(ARGV[1]) then return -1 end
redis.call('DECRBY', KEYS[1], ARGV[1])
redis.call('INCRBY', KEYS[2], ARGV[1])
-- 结算阶段（另一脚本）：frozen-=freeze, balance += (freeze-actual)
```
对账：每日 cron 校验 `Σ(ledger) == balance 初始+充值-消费`，不平告警并冻结该 uid 代采（BYOM 不受影响）。
### 6.3 支付回调
```
POST /v1/pay/callback   # 聚合支付异步通知
校验签名 → order_id 幂等 → balance += amount → ledger 追加
→ 引擎轮询 /v1/wallet 感知到账（本地缓存同步）
```

## 7. 合规 Never 层（规则表）
| 检查点 | 规则 | 处置 |
|---|---|---|
| 输入 | 用户上传视频/他人成片文件（按扩展名+时长+来源声明） | 拒绝 + 说明合法替代（授权网文） |
| 输入 | 剧本文本命中红线词库（涉政/低俗/侵权人名） | 标注风险项供 CP-1 展示，高危直接拒绝生成 |

| 导出 | `ai_badge` 恒 true（API 忽略 false） | ffmpeg 烧录标识水印 |
| 发布 | 发布文案强制含 AI 生成声明 | 模板锁定段落，LLM 只填正文 |
