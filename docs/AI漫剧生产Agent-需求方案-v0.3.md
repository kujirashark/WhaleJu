# AI 漫剧生产 Agent：需求方案（v0.3）
> 上游：`AI漫剧生产线-市场与需求分析-v0.1.md`、`AI漫剧生产工具-竞品格局与产品需求方案-v0.2.md`
> 本文回答：**怎么让不会用 AI 工具的人，通过对话快速产出漫剧？Agent 的边界、行为约束、交互流程与验收标准是什么？**
> 按 AI 功能需求六模块（任务定义/输入输出契约/质量标准/异常降级/反馈闭环/行为约束）设计。
---
## 一、定位：Agent 是交互层，不是新引擎
```
v0.2 的定位不变：多模型调度 + 成本账本 + 成片率分析（引擎层）
v0.3 新增：对话式 Agent（交互层）
    ├── 专业模式：工作台 UI（给工作室，v0.2 方案）
    └── 小白模式：对话式 Agent（给零基础创作者，本文）
        ↓ 同一套引擎
即梦 / 可灵 / 海螺 / TTS / 剪辑合成
```
**一句话定位**：用户用说人话的方式描述想做的剧，Agent 像制片人一样带着他走完"剧本→定妆→分镜→生成→成片"，全程对话确认，不需要懂任何 AI 工具。
**产品逻辑的核心判断（来自行业实测）**："完全零人工介入的全自动成片，现阶段会带来极高返工率和内容风险"（尧图/澎湃调研）。因此 **Agent 的价值不是消除人工，而是把"专业校验"翻译成"小白也能回答的三个问题"**——这是与市面上"一键成片"工具的本质区别，也是质量护城河。
## 二、六模块设计
### 模块 1：任务定义
| 项 | 内容 |
|----|------|
| 谁 | 零基础创作者：有网文/有想法/想做账号的普通人，不会写提示词、不懂分镜 |
| 什么情况 | 想做一部漫剧发抖音/视频号变现，被工具门槛挡住 |
| 当前成本 | 学习 5+ 工具、提示词工程、剪辑，入门 2-4 周（社群反馈口径，估算） |
| AI 帮到哪一步 | **草稿+陪跑**：剧本给草稿、分镜给建议、生成自动跑、成片给预览；关键节点必须用户确认（见模块 5 行为约束） |
### 模块 2：输入与上下文契约
| 输入 | 契约 | 缺失处理 |
|------|------|----------|
| 创意描述（一句话~一段话） | 文本，≤2000 字 | 追问："想做哪种题材？有没有参考的爆款类型？"（选项卡给出合规题材库） |
| 原创剧本/授权小说文本 | 文本文件 | 无则 Agent 由创意生成剧本草稿 |
| **原剧视频/他人成片** | **❌ 拒绝（版权红线，硬约束）** | 检测到即解释原因，引导到"授权 IP 池/原创剧本"路径 |
| 风格偏好 | 选项（古风/现代/奇幻/二次元…） | 不选则按题材给默认风格并说明 |
| 预算 | 金额区间 | 不填则默认"经济档"（海螺跑量为主），并展示预估成本 |
### 模块 3：输出契约
| 阶段 | 输出结构 | 证据/可编辑性 |
|------|----------|---------------|
| 剧本草稿 | 分集大纲 + 每集爽点标注 | 每条爽点可点击改写；全文可编辑 |
| 角色定妆 | 每角色 3 张多角度参考图 | 可重roll（保留语义，换图）；锁定后进资产库 |
| 分镜表 | 镜头号/画面描述/时长/预计成本 | 表格可逐行改；成本实时联动账本 |
| 视频段落 | 逐镜头成片 + 通过率标记 | 单镜头可重生成；废弃原因记录 |
| 成片 | 带字幕配音的完整视频 + **AI 生成标识**（合规强制） | 导出 MP4 + 平台竖版适配 |
结构化优先：所有输出为结构化数据（JSON 台账）+ 预览界面，而非整段自然语言。
### 模块 4：质量标准与验收样本
| 维度 | 可测标准（V1 目标） |
|------|---------------------|
| 剧本事实性 | 爽点标注与剧情对应（人工抽检 50 集通过率 ≥90%） |
| 角色一致性 | 锁定资产后多镜头人脸/服装复现崩坏率 ≤15%（对齐行业头部水平，估算） |
| 分镜一次通过率 | 经济档 ≥50%（行业均值约 40%），精品档 ≥65% |
| 成本预估误差 | 实际 vs 预估 ±20% 内 |
| 验收样本 | 覆盖：常见题材×3 / 一句话极简输入 / 预算缺失 / 原剧上传拒绝 / 生成连续失败 5 次 / 未成年人向内容拒答 |
### 模块 5：异常降级与人工接管（对话式检查点设计）
**三个必须停下来问的检查点**（把专业校验翻译成小白问题）：
| 检查点 | Agent 问什么（小白能懂） | 背后拦住什么专业风险 |
|--------|--------------------------|----------------------|
| CP-1 剧本确认 | "第 3 集男主的复仇是剧情高潮，这样写可以吗？（附大纲）" | 剧情逻辑漏洞、价值观风险 |
| CP-2 定妆锁定 | "这三个角色长这样可以吗？后面全剧都用这张脸" | 一致性返工的最大源头 |
| CP-3 样片验收 | "这是第 1 集前 30 秒，能接受吗？"（附预览） | 整集报废——投产前止损 |
**降级策略**（不是统一"系统繁忙"）：生成失败→自动换模型重试；连续失败→降画质档位并告知成本变化；预算将尽→展示剩余额度和"最小可行成片"选项；用户中途离开→保留全部进度资产，回来可从任一检查点续作。
### 模块 6：反馈与版本闭环
- 每个检查点的"采纳/重roll/手改"都记录，反哺提示词模板库
- 每次成片关联：模型版本+提示词版本+资产版本（可复现）
- 字段级反馈：用户改了哪个爽点、重roll了哪张脸 → 沉淀为该用户的风格偏好
### AI 行为约束三层（红线内建）
| 层级 | 规则 |
|------|------|
| Always | 展示预估成本再扣费；生成内容自动加 AI 标识；引用授权 IP 时展示授权来源 |
| Ask first | 单集成本将超预算 50%；涉及医疗/法律/金融情节；换模型导致画质降档 |
| **Never** | **接受未授权原剧/他人成片作为输入；生成 11 条内容红线题材；绕过检查点直接全片投产；在用户未确认预算前扣费** |
## 三、核心用户旅程（对话流）
```
用户：我想做一个逆袭题材的漫剧，预算 200 块
Agent：好，先给你 3 个逆袭题材剧本方向（附爽点大纲）… 选一个或让我改
      ↓ CP-1 剧本确认
Agent：主角定妆 3 张参考图，选一张锁定（全剧同脸）
      ↓ CP-2 定妆锁定
Agent：按预算拆了 24 个镜头：关键 6 镜走可灵、过场 18 镜走海螺，
       预估 ¥173，超预算会先问你。开始生成？
      ↓（生成中，进度可视，失败自动重试）
Agent：第 1 集前 30 秒样片好了，看看？
      ↓ CP-3 样片验收
Agent：全部 3 集完成，总成本 ¥168（预估 ¥173）。
       已加 AI 标识，导出竖版 MP4 + 发布建议。
```
## 四、竞品对照与差异化
| 竞品 | 形态 | 我们的差异 |
|------|------|-----------|
| Flova（36氪报道的对话式创作 Agent） | 对话式流程 | Flova 接创意→分镜→生成；我们多了**成本账本+跨厂商调度+检查点止损** |
| 橙星梦工厂（八大智能体） | 一站式平台 | 无对话式陪跑；我们有检查点设计与成本透明 |
| 角小蛙/漫小芽（一键成片） | 模板工具 | 一键=黑盒返工高；我们是"对话确认+止损" |
| 阅文漫剧助手 | IP 平台 | 服务网文改编；我们中立支持任意授权来源 |
差异化一句话：**别人卖"一键"，我们卖"陪跑+算账"——小白要的不是全自动，是有人带着做对。**
## 五、技术架构（V1 业余可实现）
```
┌─ 对话层：Web 对话 UI（流式） / 微信小程序（V2）
├─ Agent 编排：LLM（DeepSeek/Qwen）+ 工具调用规划器
│    工具集：剧本生成器 / 分镜规划器 / 角色定妆 / 多模型调度(v0.2引擎) /
│            账本查询 / 合规检查器(红线词库+原剧输入检测)
├─ 引擎层：v0.2 调度中枢（FastAPI 任务队列 + 成本账本）
└─ 模型层：即梦/可灵/海螺(用户Key或代采) + TTS + 剪辑合成(ffmpeg)
```
关键实现决策：**Agent 编排不训练模型，纯 prompt + 工具调用**（function calling），检查点=编排器的状态机暂停位——业余开发量可控，先跑通再谈优化。
## 六、定价调整（小白档）
| 档 | 定价 | 内容 |
|----|------|------|
| 体验 | ¥9.9/集首集 | 含 1 集全流程陪跑（约 30-60 镜），亏本引流换口碑 |
| 标准 | ¥99/月 | 每月 3 集额度 + 账本 |
| 算力 | 按量（用户 Key 或代采 +12%） | 与 v0.2 一致 |
对标锚点：角小蛙/漫小芽 15-30 元/月是"工具"价；我们收的是"陪跑制片"价，且**每单先展示预估成本**，信任前置。
## 七、风险与验收
| 编号 | 风险 | 应对 |
|------|------|------|
| RK-01 | 小白期望过高（以为是"说一句话出好莱坞"），成品落差大 | 首屏预期管理文案 + CP-3 样片先行；体验档先给 30 秒样片再收全款 |
| RK-02 | 检查点被用户嫌烦，跳单到"一键"竞品 | 每个检查点 ≤30 秒可完成；提供"信任模式"（跳过 CP-1，但 CP-2/3 不可跳） |
| RK-03 | 版权红线被用户绕过（改后缀/截图上传原剧） | 输入检测（视频/成片指纹）+ 服务条款 + Never 层硬拦截 |
| RK-04 | 对话式编排的 token 成本侵蚀利润 | 剧本/分镜等重活走结构化调用不走对话；对话只做确认与引导 |
**V1 验收定义（最小闭环）**：一个真实零基础用户，从"一句话想法"到"3 集带 AI 标识的成片"，全程对话完成，人工介入 0 次（Agent 内检查点除外），总耗时 ≤2 小时（含生成等待）。
