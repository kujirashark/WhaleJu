## 一、先看行业共识：竞争已经不在"生成"上了
两条关键行业判断（来源：36氪《Flova、Seko、LibTV"战争升级"》、澎湃《43万部之后》）：
> "模型决定了画面的天花板，**流程决定了内容能不能稳定交付**。"
> "AI 省掉的是拍摄成本，**没有自动省掉制作管理成本**——角色前后不一致、风格不统一、提示词版本混乱、修改一处影响一串，都变成新的返工成本。"
实践数据佐证：心视觉 300 人团队资产锁定后，单集制作从 1 小时压到 20 分钟；行业分镜一次通过率约 40%，头部工具能做到 75%。**返工，才是成本的大头。**
## 二、竞品格局（三层，均已有人重兵驻守）
| 层 | 代表玩家 | 定价（公开口径） | 特点 |
|----|----------|------------------|------|
| L1 生成模型层 | 即梦（字节）、可灵（快手）、海螺（MiniMax）、Seedance | 即梦会员 30 元/月、可灵 50 元/月、可灵单条约 0.45 元 | 大厂主场，卷画质与一致性 |
| L2 一站式 C 端工具 | 角小蛙、纸鸢、漫小芽、白日梦 | 免费增值，会员 15-30 元/月 | 模板化严重、画风上限低，适合零基础 |
| L3 B 端产线工作台 | **神经猫 Catimind Ani（B 端市占 60%+，头部百强工作室 92% 在用）**、万兴剧厂、阅文漫剧助手（699 元/月）、360 纳米（公测免费）、商汤 Seko、百度 Hogee、Flova、LibTV | 定制/项目制、订阅 | 重、贵、销售驱动，解决资产/流程/交付 |
**直接做 L2 或 L3 = 与 300 人团队和上市公司正面竞争，单人业余做不了。**
## 三、缝隙在哪：从真实痛点反推
制作方的五大真实痛点（澎湃/数商云/电影界横评归纳）：
| # | 痛点 | 现状 |
|---|------|------|
| P1 | **工具碎片化**：定妆用即梦、生成用可灵、跑量用海螺，素材散落各处 | 横评实测"三工具分工比单工具省 1/3 成本"，但**靠人肉切换和搬运** |
| P2 | **成本不透明**：算力烧了多少、哪个环节返工最多、单集真实成本多少，算不清 | 数商云列为痛点第四；没有轻量工具解决 |
| P3 | **一致性返工**：一次通过率行业约 40%，废片重跑是最大隐性成本 | B 端工作台用"资产锁定"解决，但轻量市场没人管 |
| P4 | **合规流程**：备案、AI 标识、授权链路 | 少数工具提"分级商用凭证"，整体薄弱 |
| P5 | **人机协同节点**：全自动=高返工，需要剧本校验/样片校验/成片审核的分级流程 | 工作台有，轻量工具没有 |
**缝隙判断**：P1+P2（多模型编排 + 成本/成片率核算）是**唯一一个不需要大团队、纯软件能力、且无人以轻量形态解决**的痛点组合。P3 的资产锁定是二期方向。
## 四、产品定位：AI 漫剧"调度与成本中枢"
### 4.1 一句话定位
**不做生成、不做剪辑，做生成工具之间的"调度层+账本"**——帮制作团队把即梦/可灵/海螺按最优分工跑起来，并算清每一集的真实成本。
对标类比：不改画笔，做画材管理柜+记账本。生成是即梦可灵海螺的事，**"用哪个、跑几次、花了多少、废在哪"是我的事。**
### 4.2 为什么这个定位适合你
| 依据 | 说明 |
|------|------|
| 能力匹配 | 全 API 调度、任务编排、成本统计=你的自动化流水线主场（FastAPI/队列/报表） |
| 资源匹配 | 你有 MiniMax API 资源=海螺跑量通道有成本优势，甚至可做"代采算力"加价模式 |
| 竞争匹配 | 避开 L1/L3 主战场；聚合层无重兵（大厂互相不聚合对手，工作台不屑做轻量） |
| 业余匹配 | 交付物是软件不是内容；用户自助；无驻场义务 |
### 4.3 核心功能（FR，V1 范围）
| 编号 | 功能 | 关键规则 | 验收标准（GWT） |
|------|------|----------|-----------------|
| FR-01 | **多模型任务编排** | 一个分镜清单导入 → 按镜头类型自动路由（关键镜头→即梦/可灵，过场→海螺）→ 队列化批量提交 → 失败自动重试 | Given 30 个镜头的分镜表，When 提交，Then 按路由规则分发，单镜头失败自动重试 ≤3 次并记录 |
| FR-02 | **成本账本** | 每次调用记账（模型/条数/单价/项目/集数）；单集成本自动汇总；预算超支告警 | Given 一集 30 镜头完成，When 查看账本，Then 可见"即梦 6 条×单价+可灵 14 条+海螺 10 条=本集总成本" |
| FR-03 | **成片率分析** | 标记每次生成"可用/废弃+废弃原因"；按模型/镜头类型/提示词版本统计一次通过率 | Given 本月 600 次生成，When 查看报表，Then 可见"可灵过场镜头通过率 78% vs 关键镜头 45%" |
| FR-04 | **素材回收站** | 生成结果按 项目→集→镜头 三级归档，统一预览、批量导出交付 | Given 跨 3 个工具生成，When 导出，Then 统一目录结构交付 |
| FR-05 | 提示词版本管理 | 镜头提示词带版本；废弃可追溯到提示词差异 | — |
| FR-06 | API Key 自带 | 用户填自己的即梦/可灵 Key；可选"代采算力"（用你的 MiniMax 通道，加价 10-15%） | — |
### 4.4 版本规划
| 版本 | 内容 | 逻辑 |
|------|------|------|
| V1（4-6 个月业余） | FR-01~04：调度+账本+成片率 | 最薄可用 wedge，先帮用户省钱+算清账 |
| V2 | 资产一致性模块（角色库锁定、参考图批量注入）| 补 P3，向工作台靠半步 |
| V3 | 合规包（备案材料清单生成、AI 标识批处理、授权链路台账）| 补 P4，政策红利 |
## 五、目标用户与销售
| 用户 | 付费理由 | 触达 |
|------|----------|------|
| **3-10 人小工作室/承制团队**（主力） | 直接省钱：混用调度省 1/3 生成成本，成片率数据帮砍废片 | AI 短剧/漫剧社群、贴吧、B 站工具测评生态 |
| 个人量产创作者 | 账本算清"这号到底赚不赚钱" | 抖音/B 站教程内容（复用你的内容自动化） |
| 不做：大型工作室 | 神经猫/万兴的地盘，销售驱动 | — |
**定价（V1 保守形态）**：
| 版本 | 定价 | 逻辑 |
|------|------|------|
| 免费版 | ¥0 | 单项目、月 200 次调度，换反馈 |
| 专业版 | **¥99/月 或 ¥899/年** | 对标"省下的 1/3 生成成本"——一个百镜项目省几百元，一月两单回本 |
| 代采算力 | 成本 +10-15% | 海螺/MiniMax 通道加价，绑定你的 API 资源优势 |
## 六、主要风险（诚实清单）
| 编号 | 风险 | 等级 | 应对 |
|------|------|------|------|
| RK-01 | **大厂开放编排能力**（即梦出一键漫剧、或可灵开放跨模型 API），聚合层被抽空 | 高 | 聚焦"跨厂商中立+成本账本"（大厂不会帮你算对手的账）；加速做资产/成片率数据壁垒 |
| RK-02 | 上游 API 改版/涨价/限额 | 高 | 模型适配层抽象化，新模型 2 周内可接入；不压注单一厂商 |
| RK-03 | 竞品下沉：工作台出轻量版 | 中 | 靠"中立第三方+个人开发者性价比"错位；小团队迭代快 |
| RK-04 | 用户太少（小工作室付费习惯未养成） | 中 | 先免费版渗透社群攒案例；教程内容持续引流 |
| RK-05 | 政策波及：如果漫剧大盘退潮，工具需求萎缩 | 中 | 工具层多模型多场景（漫剧/推文/广告视频），不完全绑定漫剧 |
## 七、与"接单搭线"的关系
图上那个"需要有成熟项目经验"的甲方需求若真实存在，**接单本身就是你工具的第一批种子用户和验证场景**：给甲方搭线时用自家工具跑，交付工具费+工具免费共创，一鱼两吃。
## 八、下一步（30 天）
1. **W1-2**：跑通"海螺 API 批量生成分镜图"最小调度 demo（用你的 MiniMax 资源，零外部成本）
2. **W2-3**：接入第二个模型（即梦或可灵 API），完成路由规则 v1
3. **W3-4**：账本+成片率报表雏形；在 1-2 个 AI 短剧社群发"免费帮你算单集成本"工具贴，验证需求
4. **W4**：复盘——有没有工作室愿意把分镜表交给你跑？→ 决定 V1 是否立项
